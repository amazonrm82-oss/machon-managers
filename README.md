# מכון פוירשטיין

שתי המערכות של המכון, מאחורי עמוד בחירה אחד.

```
פתיחת האפליקציה
        │
        ▼
   index.html            בחירה: למידה או ניהול
        │
        ├── learn.html   מערכת הלמידה  → התחברות עם Microsoft 365 של המכון
        │
        └── manage.html  מערכת הניהול  → התחברות עם סיסמת תפקיד
```

## הקבצים

| קובץ | מה זה |
| --- | --- |
| `index.html` | עמוד הבחירה — הלוגו, ושני כרטיסים: למידה / ניהול |
| `learn.html` | מערכת הלמידה (נבנה מ-`learn-src/` — לא לערוך ידנית) |
| `manage.html` | מערכת ניהול התפעול הארצי |
| `projects.html` | ניהול פרויקטים (נפתח מתוך מערכת הניהול) |
| `ms-config.js` | הגדרות ההתחברות ל-Microsoft — ניתן לעריכה בלי בנייה מחדש |
| `logo.svg` | הלוגו הרשמי — **עדיין לא הועלה**, ראו למטה |
| `learn-src/` | המקור של מערכת הלמידה + הוראות הגדרת ההתחברות |
| `supabase/` | פונקציות השרת של מערכת הניהול |

## הלוגו

עמוד הבחירה ומסך ההתחברות ללמידה טוענים את `logo.svg` (ואם אין — `logo.png`).
עד שהקובץ יעלה, מוצג סימן חלופי: טבעת בארבעת צבעי המכון עם השם.

להעלאה: לשים קובץ בשם `logo.svg` בשורש הריפו ולדחוף. אין צורך לשנות קוד —
הוא ייכנס גם לכותרת וגם כסימן מים ברקע.

## בנייה

`learn.html` נבנה מ-`learn-src/`. הבנייה רצה אוטומטית בפריסה, ולפיתוח מקומי:

```bash
node build-learn.mjs
python3 -m http.server 8080     # ואז http://localhost:8080
```

`index.html`, `manage.html` ו-`projects.html` נערכים ישירות.

## פריסה

דחיפה ל-`main` מפעילה את `.github/workflows/deploy.yml`, שבונה את
`learn.html` ומפרסם את האתר ל-GitHub Pages.

## התחברות

- **ניהול** — סיסמת תפקיד, נבדקת בפונקציית `role-auth` בסופאבייס.
  הפרטים ב-`SECURITY_FIX_README.md`.
- **למידה** — חשבון Microsoft 365 של המכון (Entra ID). הגדרה חד-פעמית
  לפי `learn-src/README.md`; עד שתתבצע, מסך ההתחברות מציג כניסת דמו
  מסומנת במפורש.
